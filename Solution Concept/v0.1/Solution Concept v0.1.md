# 3. Концепция целевого решения
## 3.1 Краткое описание решения

**Пользователи:** Диспетчеры, ответственные мастера, исполнители, представители клиентов, руководитель сервисного направления

**Ценность:** Сейчас все завки ведутся в получном режиме, диспетчера не справляются с нагрузкой, исполнители не видят всех своих работ и приоритетов по ним, данные по заявкам теряются, заявки могут быть не исполнены вовремя, клиенты не видят всей истории по заявкам. С введением централизованной системы для управления заявками все пользователи смогут  отслеживать по своим заявкам, создание заявок для диспетчеров и представителей клиентов в упрощенном режиме, мастера смогут прозрачно отслеживать список выездных работ и оценивать их по приоритеатам, руководитель сервисного направления сможет отслеживать проблемные  заявки и находить причину. 

**Ключевые возможности:** Создание заявок, назначение выездных мастеров внутри системы, возможность отслеживать всю историю по заявке, прикреплять файлы к заявке, вести переписку внутри системы.

**Каналы:** Веб-интерфейс, интеграция с почтой, телефония
